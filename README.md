# Happy Birthday, Marniè

An interactive, cinematic birthday evening by the sea.

## Add the personal media

Create these folders and add the files using the exact names below:

```text
assets/
  photos/
    photo1.jpg
    photo2.jpg
    photo3.jpg
    photo4.jpg
    photo5.jpg
    final.jpg
  music/
    jhol.mp3
    waves.mp3
```

The website still runs when photos or ocean ambience are missing. Photo spaces use subtle placeholders and unavailable audio is ignored.

## Preview

Open `index.html` directly, or run a local server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

In the GitHub repository, open **Settings → Pages**, select **Deploy from a branch**, then choose the `main` branch and `/ (root)`.
